# Bunker 100

A gritty, late-90s inspired post-apocalyptic tactical RPG and first-person shooter set within the unforgiving ruins of the Dust Sea. Built natively for the web.

## Overview

**Bunker 100** drops you straight into a retro-futuristic nightmare. The world outside is a scorched wasteland; inside, you are a survivor relying on military surplus gear, flickering command terminals, and sheer grit. Packaged as a lightweight, browser-accessible experience, it channels the analog-heavy atmosphere of classic late-90s nuclear RPGs.

## Core Features

- **Old-School RPG Mechanics:** Navigate a deep survival loop driven by core stats, skills, traits, and active objectives.
- **Tactical Shooter Action:** Fast, responsive browser-based gunplay powered by modern WebGL2 and Three.js.
- **Bleak Retro-Futurism:** An unmistakable visual identity defined by a sodium-lamp amber and oxidized copper palette against a burnt umber and ink background.
- **Industrial Aesthetic:** Styled with heavy stamped steel plates, riveted corners, and mono-spaced data formatting.
- **Single-File Architecture:** Designed to run seamlessly without heavy launchers, installations, or asset packs.

## Development & AI-Assisted Pipeline

This project was conceptualized, architected, and built natively for the web through an intensive collaborative development pipeline utilizing **Claude** and **Gemini AI**, shaping open-source codebases and modern web tech into a totally unique survival experience.
